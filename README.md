# 僕のノート · Boku no Nōto

[![Deploy to GitHub Pages](https://github.com/roro4x/boku-no-noto/actions/workflows/deploy-pages.yml/badge.svg)](https://github.com/roro4x/boku-no-noto/actions/workflows/deploy-pages.yml)

Личный ретро-сайт о японском языке: учебная папка уровня N5, архив японских текстов в Markdown, пиксельная лягушка и небольшой музыкальный плеер.

**Сайт:** [roro4x.github.io/boku-no-noto](https://roro4x.github.io/boku-no-noto/)

## Возможности

- единый каталог грамматики, лексики и кандзи N5 с поиском;
- архив японских текстов с поиском по названию и фильтрами по году и месяцу;
- рендеринг Markdown с поддержкой GitHub Flavored Markdown;
- переключение интерфейса между русским и японским языками;
- кассетный аудиоплеер без автоматического воспроизведения;
- адаптивная вёрстка и доступная клавиатурная навигация;
- автоматическая проверка и публикация через GitHub Actions.

## Стек

- **React 19** — интерфейс и компоненты;
- **TypeScript** — типизация приложения и данных;
- **Vite** — локальная разработка и production-сборка;
- **React Markdown**, **remark-gfm** — отображение Markdown-текстов;
- **Vitest** — автоматические тесты;
- **CSS** — дизайн-система и адаптивная ретровёрстка без UI-фреймворка;
- **GitHub Actions + GitHub Pages** — непрерывная проверка и публикация.

## Локальный запуск

Требуется актуальная LTS-версия Node.js и npm.

```bash
npm ci
npm run dev
```

Vite выведет адрес локального сервера в терминале.

## Команды

```bash
npm run dev             # локальный сервер разработки
npm run build           # обычная production-сборка
npm run build:pages     # сборка с базовым путём /boku-no-noto/
npm run preview         # локальный просмотр production-сборки
npm run check           # проверка TypeScript
npm test                # тесты Vitest
npm run data:validate   # валидация учебных данных N5
npm run contrast:check  # проверка контрастности основных цветовых пар
```

## Добавление текста

Создайте файл с расширением `.md` в `content/texts`. Имя файла станет частью hash-ссылки, поэтому используйте короткий стабильный slug латиницей.

```md
---
title: 雨の日の散歩
date: 2026-09-18
description: Короткий текст о прогулке под дождём.
---

Текст начинается здесь.
```

Обязательные поля frontmatter:

- `title` — название публикации;
- `date` — дата в формате `YYYY-MM-DD`;
- `description` — краткое описание для списка публикаций.

После добавления файл автоматически попадёт в архив при следующей сборке.

## Маршруты

Приложение использует hash-навигацию, совместимую со статическим хостингом GitHub Pages:

- `#/` — главная;
- `#/nihongo/grammar` — грамматика;
- `#/nihongo/vocabulary` — лексика;
- `#/nihongo/kanji` — кандзи;
- `#/texts` — архив текстов;
- `#/texts/<slug>` — отдельная публикация.

## Публикация

Push в ветку `main` запускает `.github/workflows/deploy-pages.yml`. Workflow устанавливает зависимости через `npm ci`, выполняет тесты и проверки, собирает проект и публикует каталог `dist` в GitHub Pages.

Сборка публикуется только после успешного прохождения всех проверок.

## Учебные данные

Сведения об источниках, версиях и лицензиях набора N5 находятся в `public/data/n5/sources.json`, `public/data/n5/OPENJLPT-NOTICE.md` и `public/data/n5/LICENSE-CC-BY-SA-4.0.txt`.
