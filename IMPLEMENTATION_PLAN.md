# 僕のノート — план реализации

## Этап 1. Визуальный фундамент — готово

- React + TypeScript + Vite;
- общий SiteFrame, шапка, меню, sidebar и footer;
- адаптивная ретро-композиция;
- focus-visible, skip-link и reduced-motion.

## Этап 2. Главная страница — готово

- приветственная записка;
- заметный переход в 日本語 · N5;
- пиксельный маскот в шапке;
- музыкальный блок с предоставленной записью и без автозапуска;
- компактная информация о сайте и декоративные баннеры.

## Этап 3. Публичный набор N5 — готово

- manifest и три category JSON;
- 20 грамматических конструкций, 662 слова и 79 кандзи;
- русские значения, японские чтения и примеры;
- OpenJLPT, JMdict и KANJIDIC2 с лицензиями;
- автоматическая проверка схемы, ID, порядка и sourceRefs.

## Этап 4. Каталог 日本語 · N5 — готово

- внутренняя навигация по трём категориям;
- списки grammar, vocabulary и kanji;
- поиск с Unicode-нормализацией;
- прямые ссылки на подробные карточки;
- выдача длинного списка порциями;
- loading, empty и error состояния.

## Этап 5. Текущая корректировка — готово

- боковое меню содержит только «Главная», «日本語 · N5» и «読みもの · Тексты»;
- категории оставлены только внутри учебной страницы;
- каталог упрощён до чтения и поиска;
- документация приведена в соответствие с фактическим продуктом.

## Этап 6. Markdown-архив и визуальные ассеты — готово

- добавлена папка `content/texts` с frontmatter-контрактом;
- реализованы архив, поиск по названию, год и месяц;
- реализована страница публикации с GFM Markdown;
- добавлены прозрачные пиксельные ассеты лягушки и пруда;
- подключена предоставленная MP3-запись, ручное воспроизведение, остановка и громкость;
- добавлено переключение языка оболочки между русским и японским.

## Этап 7. Выпуск

- проверить 320, 390, 768, 1024, 1280 и 1440 px;
- проверить keyboard-only, 200% zoom и reduced motion;
- выполнить dataset validation, unit tests, typecheck и build;
- настроить GitHub Actions и публикацию GitHub Pages;
- выполнить smoke test опубликованной версии.

## Ожидает материалов владельца

- дополнительные музыкальные файлы и их порядок;
- реальные Markdown-тексты, которые заменят демонстрационные публикации;
- решение о публикации и домене.

## После первой версии

Рассматривать отдельными решениями:

- новые небольшие разделы homepage;
- чистые URL вместо hash-routing;
- дополнительные языки интерфейса помимо русского и японского;
- MIDI-синтезатор;
- offline-кэш публичного каталога.

Фотословарь и соло-RPG не добавляются без пересмотра продуктовых границ.
