# Как добавлять японские тексты

Положите новый файл `.md` в папку `content/texts`. В начале файла обязательны заголовок и дата:

```md
---
title: 雨の日の散歩
date: 2026-09-18
description: Короткий текст о прогулке под дождём.
---

Текст начинается здесь.
```

Дата записывается в формате `YYYY-MM-DD`. Имя файла становится частью прямой ссылки, поэтому лучше использовать короткий стабильный slug латиницей.
