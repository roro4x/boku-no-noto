# Как добавлять японские тексты

Положите новый файл `.md` в папку `content/texts`. В начале файла обязательны заголовок и дата:

```md
---
title: 雨の日の散歩
date: 2026-09-18
description: Короткий текст о прогулке под дождём.
---

Текст начинается здесь.
```

Дата записывается в формате `YYYY-MM-DD`. Имя файла становится частью прямой ссылки, поэтому лучше использовать короткий стабильный slug латиницей.

Учебные материалы для подраздела «Тексты для чтения» добавляются по тем же правилам в `content/readings`.

## Как добавлять личные заметки

Заметки используют тот же frontmatter. Положите `.md`-файл в `content/notes`; его имя станет частью ссылки `#/notes/<slug>`. Текст заметки отображается на исходном языке и не переводится вместе с интерфейсом.
