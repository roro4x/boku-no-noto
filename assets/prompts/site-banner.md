# Баннер 僕のノート · 88×31

Обновлён 2026-10-20 по просьбе владельца: только японское название и латинская
подпись, без иллюстрации. Кремовая бумага, зелёная двойная рамка и фон шалфея
сохраняют оформление сайта.

Редактируемый исходник: `assets/site-banner.svg`.
Публикуемый файл: `public/assets/banners/boku-no-noto.png`, 352×124 px.
HTML вставляет его в размере 88×31; экспорт в четырёхкратном разрешении сохраняет
чёткость на экранах с высокой плотностью пикселей и при увеличении.
Текст фиксируется в PNG и не зависит от шрифтов компьютера посетителя.
Использована системная японская гарнитура Hiragino Sans.

Повторный экспорт через Sharp (librsvg):
`sharp('assets/site-banner.svg', { density: 288 }).png().toFile('public/assets/banners/boku-no-noto.png')`.
