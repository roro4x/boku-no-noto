# Форматы разделов

## Мои тексты

- Папка: `content/texts/`
- Маршрут списка: `#/texts`
- Маршрут публикации: `#/texts/<slug>`
- Файл: `<slug>.md` с обязательным frontmatter `title`, `date`, `description`.

## Тексты для чтения

- Папка: `content/readings/`
- Маршрут списка: `#/texts/reading`
- Маршрут публикации: `#/texts/reading/<slug>`
- Формат совпадает с «Моими текстами».

## Заметки

- Папка: `content/notes/`
- Маршрут списка: `#/notes`
- Маршрут публикации: `#/notes/<slug>`
- Формат совпадает с текстами; тело заметки остаётся на исходном языке.

Для этих трёх разделов используй шаблон:

```md
---
title: Название
date: YYYY-MM-DD
description: Краткое описание для списка
---

Тело материала
```

Парсер находится в `src/data/textPosts.ts`. Поля `title` и `date` обязательны. `description` поддерживается и должна присутствовать для единообразия, даже если пользователь предпочитает пустое значение `""`. Если значение содержит двоеточие или ведущие/замыкающие пробелы, заключи его в одинарные или двойные кавычки. Не добавляй неизвестные поля: текущий интерфейс их не использует.

## Промпты

- Исходный файл: `content/prompts/<filename>.md` без добавленного frontmatter и без изменения текста пользователя.
- Каталог: массив `prompts` в `src/data/prompts.ts`.
- Маршрут: `#/prompts/<id>`.

Добавь запись типа `PromptEntry`:

```ts
{
  id: 'stable-kebab-case-id',
  title: 'Понятный заголовок',
  description: 'Кратко объясняет назначение промпта.',
  fileName: 'prompt-file-name.md',
  tags: ['поиск', 'тематика'],
  addedAt: 'YYYY-MM-DD',
},
```

`title`, `description` и `tags` участвуют в поиске. Выбирай небольшое число конкретных тегов из языка и темы самого материала, не добавляя неподтверждённых возможностей. `addedAt` необязателен по типу, но для новых записей указывай его, чтобы сохранить дату добавления.
