# Добавление ссылки на сайт

Добавляй ссылку через существующий конфигурационный каталог, не изменяя компонент `LinksDirectory` без отдельной необходимости.

## Рабочий процесс

1. Изучи `src/data/links.ts`, `src/components/LinksDirectory.tsx` и соседние файлы в `public/assets/banners/`, чтобы сохранить текущий формат.
2. Проверь, что URL абсолютный и использует `https://`, если ресурс это поддерживает. Не делай сетевой запрос только ради проверки доступности, если пользователь не просил; при явной просьбе проверить ссылку используй безопасный read-only запрос.
3. Выбери уникальный короткий `id` в латинском `kebab-case`. Проверь отсутствие дубликата по `id`, нормализованному URL и имени баннера.
4. Добавь локальный баннер в `public/assets/banners/`:
   - используй предоставленный пользователем баннер, если он пригоден для веба;
   - приведи размер отображения к 88×31 без искажения значимого содержимого;
   - если баннера нет, создай простой SVG 88×31 в визуальном стиле соседних баннеров: кремовый фон, тёмная рамка, ограниченная палитра, разборчивая подпись, `viewBox="0 0 88 31"`, `<title>` и `<desc>`;
   - не подключай удалённое изображение и не встраивай data URI.
5. Добавь объект в конец `siteLinks` в `src/data/links.ts` со значениями `id`, `title`, `url`, `banner` и, только если оно полезно и предоставлено или уверенно выводится, `description`. Путь к баннеру задавай как `assets/banners/<filename>` без начального `/`.
6. Не меняй существующие ссылки и их порядок без запроса пользователя.
7. Запусти `npm test` и `npm run build`. Исправь ошибки, вызванные новой записью или баннером.
8. В итоговом сообщении укажи добавленный ресурс, URL, id и созданный баннер.

## Важные ограничения

- Не перезаписывай существующий баннер или запись при совпадении имени; выбери другой id/filename либо запроси решение, если это тот же ресурс.
- Не копируй логотип или графику с внешнего сайта без предоставленного файла или явного разрешения. Для отсутствующего баннера используй оригинальную простую композицию из текста и геометрических фигур.
- Не коммить и не публикуй изменения без отдельного запроса.
