# Промпт для этапа реализации

Скопируй текст ниже в отдельную задачу Codex, когда будешь готов начать разработку.

---

Ты работаешь над персональным сайтом **僕のノート (Boku no Nōto)** в текущем каталоге.

Начни с полного чтения следующих файлов:

1. `PRODUCT.md`
2. `DESIGN.md`
3. `SPEC.md`
4. `IMPLEMENTATION_PLAN.md`

Также прочитай project-scoped skill Impeccable в `.agents/skills/impeccable/SKILL.md`, запусти его обязательную команду `context` один раз из корня проекта и следуй подходящим references. Не запускай команды Impeccable, которым нужен работающий сайт, пока такой сайт не существует. После установки/обновления попроси меня открыть `/hooks` и одобрить проектный hook, если Codex ещё не доверяет ему.

Перед кодом:

- проверь текущее содержимое каталога и не перезаписывай пользовательские файлы;
- перечисли открытые решения из PRODUCT.md и этапа 0 плана;
- спроси только о тех решениях, без которых безопасно продолжить нельзя;
- не выдумывай источники N5, лицензии, реальные музыкальные файлы, данные владельца, GitHub repository, OAuth credentials или готовые графические ассеты;
- зафиксируй выбранный code-first/comp-first процесс Impeccable;
- сохрани заданное художественное направление «Забытая японская домашняя страница»; не превращай его в современный SaaS/dashboard с ретро-палитрой.

Реализуй проект последовательно по `IMPLEMENTATION_PLAN.md`, начиная с ближайшего неготового этапа. После каждого этапа проверь его критерии готовности и сообщи короткий результат. Каталог остаётся публичным read-only перечнем без авторизации.

Обязательные правила:

- React + TypeScript + Vite + CSS + GitHub Pages остаются основным стеком, если не найдено блокирующее основание для изменения.
- Токены и client secrets запрещены в публичном репозитории, клиентской сборке, `localStorage`, `sessionStorage`, IndexedDB, URL и логах.
- Музыка не запускается автоматически; MIDI не обещается без отдельного исследования и решения.
- Фотословарь и соло-RPG не входят в проект.
- Не создавай редактор заметок в MVP.
- Все реальные ассеты должны иметь понятное происхождение и лицензию; не подменяй отсутствующий пиксельный арт сложными CSS-иллюстрациями.

Качество интерфейса:

- первый экран показывает саму homepage, а первый экран 日本語 — рабочий каталог, не маркетинговый hero;
- русский, японский и английский отображаются корректно;
- основной текст не меньше 1rem, controls на мобильном не меньше 44×44 CSS px;
- полная клавиатурная навигация, видимый focus, достаточный контраст, `prefers-reduced-motion`;
- мобильная версия — одна колонка без горизонтального скролла;
- декоративные GIF, фактуры и рамки не мешают поиску, навигации по категориям и чтению;
- используй токены, типографику, компоненты и правила из DESIGN.md;
- осознанные ретро-исключения из рекомендаций Impeccable сохраняй, если они не вредят доступности.

Проверки:

- тестируй поиск и маршруты каталога, фильтры архива, разбор Markdown и ошибки данных;
- проверяй 320/390 px и desktop 1280/1440 px;
- запускай Impeccable audit только после появления рабочего UI и polish только в ограниченном финальном проходе;
- не запускай бесконечные циклы визуальной полировки;
- перед публикацией проверь, что Pages artifact не содержит приватные данные, токены или секреты.

Не публикуй и не создавай внешние GitHub/OAuth/hosting ресурсы без отдельного подтверждения, если действие требует аккаунта, домена, секретов или создаёт расходы. Локальную реализацию, тесты и сборку выполняй автономно в пределах согласованного этапа.
